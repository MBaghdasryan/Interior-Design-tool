# Рабочий альбом A3 (по образцу «Պարույր Սևակ 5»)

Образец (MindCraft, 47 листов A3, Archicad): штамп в правой колонке (логотип, контакты, адрес объекта, заказчик,
условные обозначения, дизайнер, раздел/лист, номер «ԴՆx.y /45», формат A3, масштаб), содержание и 4 раздела.
Генератор `apps/api/app/album` воспроизводит ту же структуру из модели проекта и добавляет 5-й раздел.

| Код | Лист (HY / RU) | Источник данных |
|---|---|---|
| — | Обложка + QR на 3D/Client Viewer | аксонометрия сцены |
| — | Բովանդակություն / Содержание | список листов |

| ԴՆ1.2 | Դեմոնտաժվող պատեր / Демонтаж | стены `status=demolish`, площади демонтажа |
| ԴՆ1.3 | Նոր էլեմենտներ / Монтаж перегородок | стены `status=new`, размеры, материал |
| ԴՆ1.4 | Եռաչափ տեսք / Аксонометрия демонтажа и монтажа | 4 вида (2 угла × демонтаж/монтаж) |

Языки: HY (по умолчанию, как образец), RU, EN; шрифт DejaVu Sans (армянский + кириллица).
White-label: данные штампа задаются в «Кабинет бюро → Штамп альбома».

Генерация: `POST /api/v1/projects/{id}/documents/album {variant_id, lang, sections}` → задача `album` → PDF + DXF + XLSX + CSV + GLB + JSON.
Типичный объём: ~40 листов, ~0.5 МБ, < 1 с на 65 м².
