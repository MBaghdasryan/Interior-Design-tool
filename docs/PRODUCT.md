# Продукт

**Renovara** — AI-платформа, превращающая пустую квартиру в реализуемый дизайн-проект с реальными товарами,
локальными поставщиками, готовым бюджетом и рабочим альбомом. Позиционирование для Армении:
*professional AI design production + verified local procurement* (B2B2C: бюро → клиент → магазины).

## Режимы

| Режим | Где в продукте |
|---|---|
| **AI Autopilot** (основной) | «Пусть ИИ решит» / «Найти товары и создать дизайн» → 3 варианта |
| Guided AI | необязательные параметры: стиль, цвета, бюджет (уровень или сумма), семья, поставщики, сохранить предметы, интервью свободным текстом |
| Manual Refinement | редактор 2D/3D: перемещение, поворот, блокировка, удаление, замена аналогом, undo/redo, версии |
| Concept Mode / Real Products Mode | источник товаров «Концепция без товаров» / «Внешний каталог»; бейдж режима на результате |

## Уровни точности

| Уровень | Когда | Ограничения |
|---|---|---|
| Concept Estimate | только фото/видео | смета ориентировочная, изделия по размерам не заказываются |
| Verified Design | план + контрольные размеры (ставится автоматически при подтверждении геометрии с контрольным размером) | заказ серийных товаров через RFQ |
| Production Ready | подтверждённый обмер (роль «Обмерщик») | заказ кухонь, шкафов и др. по размерам |

Для проекта хранятся: confidence, подтверждённые размеры, допущения ИИ, критические неопределённости, предупреждения.

## Роли (RBAC, tenant isolation)

platform_admin, platform_ops, bureau_admin, designer, client, collaborator, supplier_admin, supplier_catalog,
manufacturer, installer, verifier. Чужие проекты недоступны (404, не 403 — без утечки идентификаторов).
