# ADR-010: CAD/BIM-интеграции — что делаем сейчас, что откладываем

**Статус:** принято · 2026-10-22

## Сделано (P2-6)
- **IFC4 экспорт и редактируемый импорт** (IfcOpenShell 0.8.5): стены, проёмы с дверями/окнами, помещения с площадями; круговой тест экспорт → импорт совпадает по геометрии до 1 мм. Импорт создаёт черновик базовой геометрии для проверки.
- **RVT**: только через Autodesk APS Model Derivative (просмотр, извлечение помещений); редактируемый импорт RVT — через IFC-выгрузку из Revit. Проверка на реальном RVT бюро — заблокирована (нужен файл).

## Оценка остальных форматов и коннекторов

| Направление | Ценность для Renovara | Стоимость / риск | Решение |
|---|---|---|---|
| **BCF 2.1/3.0** (замечания к модели) | Средняя: обмен замечаниями с архитекторами, у которых есть BIM | Низкая: XML+PNG в zip; связка с нашими комментариями по GUID IFC | **Следующий шаг**, после стабильного IFC-обмена с реальным бюро |
| **OpenUSD** | Низкая сейчас: визуализация уже в GLB/three.js | Средняя: отдельный пайплайн материалов | Отложено; пересмотреть при интеграции с Omniverse/рендер-фермой |
| **APS Design Automation for Revit** (генерация RVT) | Высокая для бюро на Revit | Высокая: нужен Revit-шаблон бюро, AppBundle на .NET, квота DA | Отложено до пилота с бюро на Revit; DWG через DA уже работает (ADR-008) |
| **Archicad (Python Connection / JSON API)** | Средняя: популярен в Армении | Средняя: локальный плагин на машине архитектора, не облако | Отложено; IFC покрывает обмен геометрией |
| **SketchUp** (Ruby API / .skp SDK) | Средняя для дизайнеров | Средняя: SDK под лицензией Trimble | Отложено; экспорт GLB/DAE закрывает просмотр |
| **3ds Max** (визуализаторы) | Низкая-средняя | Высокая: Windows-плагин | Не делаем; обмен через FBX/GLB при необходимости |

## Последствия
IFC — основной открытый формат обмена; всё остальное подключается адаптерами к той же модели сцены (BuildingGraph) без изменения ядра.
