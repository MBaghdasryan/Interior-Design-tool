# ADR-007: Project Catalog Snapshot for external products

**Статус:** принято · 2026-10-21

## Контекст и решение
Внешние данные изолированы от PIM, имеют TTL, provenance и статусы; попадают в PIM только после договора/проверки.

## Последствия
Live-fetch по умолчанию выключен; включается для источников со статусом ok.
