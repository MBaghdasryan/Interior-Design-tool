# ADR-011: Мобильный обмер и приложение клиента — сначала PWA, LiDAR через RoomPlan JSON

**Статус:** принято · 2026-10-22

## Решение
- Веб-приложение устанавливается как **PWA** (`manifest.webmanifest`, `sw.js`): офлайн-оболочка, кэш только неизменяемых сборочных файлов; API, файлы и подписанные ссылки не кэшируются (персональные данные).
- **LiDAR**: импорт `CapturedRoom` JSON из Apple RoomPlan (iOS 16+; iOS 17 добавляет полигон пола) → черновик геометрии: стены, двери, окна, проёмы с уверенностью из скана; толщина стен (RoomPlan её не измеряет) принимается 100 мм и помечается допущением; без пола контур строится по стенам и тоже помечается.
- Нативные приложения (Swift/RoomPlan внутри приложения, Android ARCore) — только отдельным решением после пилота: RoomPlan-скан сейчас делается любым приложением, экспортирующим `CapturedRoom` JSON.

## Последствия
Поддержка одного кода для всех устройств; ограничения PWA на iOS (push только с iOS 16.4 при установке на экран, фоновая работа ограничена) приемлемы для обмерщика и клиента. Проверка на реальном скане квартиры — при пилоте (N99).
