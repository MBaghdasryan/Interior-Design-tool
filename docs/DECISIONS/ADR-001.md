# ADR-001: Python/FastAPI backend instead of NestJS

**Статус:** принято · 2026-10-21

## Контекст и решение
Геометрия, CV, PDF/DXF/IFC и AI-интеграции имеют лучшую экосистему в Python (ReportLab, ezdxf, Shapely, IfcOpenShell, pymupdf). Один сервис вместо пары NestJS+FastAPI сокращает сроки MVP.

## Последствия
Мастер-промпт рекомендует TypeScript API; бизнес-модули можно вынести в NestJS позже, контракт — OpenAPI (/api/v1/openapi.json).
