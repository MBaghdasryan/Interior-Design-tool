## Архитектура

- **Словари** — `apps/web/src/i18n/dict/*.ts`, типизированные `{hy, ru, en}`: все три языка обязательны на уровне типов.
- **Использование** — `useT()`, `translate()`, `tOr()`; переключение без перезагрузки; выставляется `<html lang>`.
- **Форматирование** — `src/lib/format.ts` через Intl с локалью `hy-AM` / `ru-RU` / `en-GB`: суммы AMD, проценты, м², мм, даты.
- **Перевод данных сервера:**
  - `ruleMessage`, `stepTitle`, `stepDetail` — `src/lib/messages.ts`;
  - `lineName`, `variantTitle` — `src/lib/format.ts`.
- **Единый источник для документов сервера:**
  - `apps/web/scripts/export-server-dict.mjs` выгружает разделы `works.*`, `notice.*`, `rules.*`, `enum.*`, `unit.*`, `estimate.line_*` в `apps/api/app/i18n_shared.json` (97 ключей);
  - альбом читает этот файл через `app/album/i18n.py::shared()`;
  - флаг `--check` ловит устаревший файл;
  - тест `test_shared_dictionary_covers_server_codes` проверяет, что каждый код правил, уведомлений и работ есть на всех трёх языках.
- **Лексика альбома** (штамп, легенды, узлы ГКЛ, примечания по электрике, график работ, лист утверждения) — `TX` в `app/album/i18n.py`.
- **Системные заметки к розеткам** хранят стабильный `note_key`. Для старых сцен ключ восстанавливается по тексту.
- **Голосовой ввод** использует язык интерфейса (`SPEECH[lang]`).
